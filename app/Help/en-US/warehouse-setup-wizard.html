Set up Bifrost Warehouse

Purpose

Review what Warehouse adds to Bifrost, check HTTP through Foundation, and review user access.

How to access

In Assisted Setup, choose Set up Bifrost Warehouse in Extensions.

Key fields

HTTP enabled shows this app’s Allow HttpClient Requests status. The wizard only reads it.

Actions

Show operations opens Bifrost Message Types. Documentation opens Warehouse help. Enable HTTP in Bifrost Setup opens Foundation’s wizard; Verify refreshes status. Open Users and Open Permission Sets open the standard access pages. Back and Next navigate; Finish marks setup complete.

Common tasks

For missing HTTP, ask an administrator to enable it through Foundation. Assign BIFROST WhsePost ori for warehouse posting/registering and BIFROST WhseInv ori additionally for shipment invoicing. Users also need Foundation Bifrost permission sets. Closing early leaves completion unchanged.
