Setja upp Bifröst vöruhús

Tilgangur

Kynntu þér hvað Vöruhús bætir við Bifröst, athugaðu HTTP í gegnum grunnkerfið og farðu yfir aðgang notenda.

Aðgangur

Í Aðstoðaðri uppsetningu skaltu velja Setja upp Bifröst vöruhús undir Viðbætur.

Helstu reitir

HTTP virkt sýnir stillinguna Leyfa HttpClient-beiðnir fyrir þetta forrit. Leiðsögnin les hana aðeins.

Aðgerðir

Sýna aðgerðir opnar Skilaboðategundir Bifröst. Skjölun opnar hjálp Vöruhúss. Virkja HTTP í Bifröst uppsetningu opnar leiðsögn grunnkerfisins; Staðfesta endurnýjar stöðuna. Opna notendur og Opna heimildasamstæður opna staðlaðar aðgangssíður. Til baka og Áfram færa þig milli skrefa; Ljúka merkir uppsetningu sem lokið.

Algeng verkefni

Ef HTTP er ekki virkt skaltu biðja stjórnanda um að virkja það í gegnum grunnkerfið. Úthlutaðu BIFROST WhsePost ori fyrir bókun og skráningu vöruhúss og BIFROST WhseInv ori til viðbótar fyrir reikningsfærslu afhendinga. Notendur þurfa einnig Bifröst-heimildasamstæður grunnkerfisins. Að loka fyrr breytir ekki fyrri lokastöðu.
